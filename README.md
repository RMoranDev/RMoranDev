## Projetos em destaque

**[Sistema de Biblioteca](https://github.com/RMoranDev/biblioteca-jdbc-postgres)**
Sistema em Java para gerenciamento de uma biblioteca, com arquitetura em camadas e acesso a dados via JDBC.
`Java` `JDBC` `PostgreSQL` `Maven` `JUnit`

`Java` `Spring Boot` `MySQL` `Maven`
