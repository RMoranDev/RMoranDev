### 📌 Projetos em destaque

Sistema desenvolvido em Java para gerenciamento de uma biblioteca, utilizando:

- Java
- JDBC
- MySQL
- Maven
- JUnit
- Arquitetura em camadas

API REST para gerenciamento de estoque, desenvolvida com Java e Spring Boot,
